🚀 Built an AI-Powered Marketing Campaign Dashboard — End to End!

A Superstore runs a yearly Gold Membership campaign but only 14.91% customers accept. I built a full-stack interactive dashboard to find WHO will accept & WHAT drives spending.

📊 Page 1 — KPI Dashboard
• 8 KPI cards (Customers, Income, Spend, Response Rate, Recency, Web Visits)
• 15+ interactive charts (Spend by Category, Purchase Channels, Demographics)
• 5 Slicers: Education, Marital Status, Age, Income, Children
• Cross-filtering — click any chart bar to filter the entire dashboard instantly!
• Top 10 Customers table + Strategic Recommendations

🤖 Page 2 — ML & Statistics
• Random Forest (200 trees) + SMOTE for class imbalance
• Buyer recall improved significantly after SMOTE balancing
• Feature Importance, Confusion Matrix, Classification Report
• Correlation Heatmap + Descriptive Stats (skewness, kurtosis)
• Top predictors: TotalSpend, Income, Recency

🧹 Data Pipeline
• Missing Income → Median imputation
• Outlier removal, date parsing, marital status standardization
• 6 derived columns (TotalSpend, Age_Group, TopCategory, etc.)
